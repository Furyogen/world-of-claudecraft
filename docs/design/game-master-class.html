The Game Master

A tenth class whose entire kit is the staff toolbox reimagined as spellcraft. Every ability below is an existing dev or admin command, translated into a normal, server-authoritative player spell: the moderation ladder becomes a combo mechanic, /dev spawn becomes a summon, /dev revive becomes a combat resurrect, /dev tp becomes a blink. The fantasy is the command line. The implementation is ordinary sim content.

Why cloth, and why a support role

The command set this class is built from is overwhelmingly non-damaging: heal, revive, give, teleport, despawn, silence. Building it as a damage spec would mean inventing a damage kit the source material does not contain. Cloth support keeps it honest and leaves the three specs room to differ by what they do to a fight rather than by how hard they hit it.

Signature mechanic: Citations

Real moderation escalates: a note, then a mute, then a suspension, then a ban. That ladder is the class resource loop. Cite is the builder and applies one Citation to the target (3 max, 30 sec). Verdict is the spender and consumes every stack at once, with a different effect at each count. One button, three decisions: spend early for the interrupt, or hold for the finisher and risk the stacks timing out.

Verdict at 1 stack

Warning

Silences the target for 3 sec. The cheap interrupt: available almost on demand, costs you the ladder.

Verdict at 2 stacks

Restriction

Silences for 3 sec and roots for 5 sec. The kiting answer, and the one most fights actually want.

Verdict at 3 stacks

Suspension

Banishes the target for 8 sec: untargetable, unable to act, broken by any damage. Fear diminishing returns apply, so it cannot be chained.

The decision this creates

Cite is off the global cooldown and cheap, so the ladder is always climbable, but Verdict has one charge on a 24 sec recharge. Spending it as a 1 stack silence means the banish is not there for the add pack ten seconds later. That is the whole class in one press, and it answers the interestingness test in docs/design/class-design-rules.md: it changes what you press, when you spend, and which target you pick.

Spellbook

Twenty five abilities: thirteen shared baseline, four per spec, gated with specs: [...] exactly as the warrior and mage kits already are. Every entry names the command it came from. Only eight are in the combat rotation; the rest are passives, cooldowns, or out of combat utility, which is how the shipped kits are already sized. Costs, cooldowns, and durations are shapes for review, not balance output: coefficients wait on a measured pass per docs/design/spell-balance-framework.md.

Row 20 does not stack on row 17

Each level 20 option redirects the level 17 choice rather than adding a second cooldown on top of it: area, party healing, or utility. That is the rule the design standard makes explicit, and it is the first thing a reviewer will check.

Left unmapped on purpose

/dev level, /dev gold, /dev quest, and /dev quests get no ability. Each one hands out progression: experience, currency, or quest credit. Any spell shaped like them is an economy faucet, and a class that mints progression is a balance problem rather than a design idea. If they are wanted later they belong in an economy review, not in this kit.

accounts.password, staff.manage, and ops.perf are operator surfaces with no combat reading at all, so they are out of scope by nature rather than by choice.

What building it would touch

The class is content, not new architecture. It lands through seams that already exist, which is the argument for it: the marginal cost is content authoring plus the presentation work every class needs.

Simulation
  • src/sim/types.ts, add 'gamemaster' to the PlayerClass union
  • src/sim/content/classes.ts, one ClassDef plus the ability records
  • src/sim/content/choice_rows.ts, the six rows
  • The Citation mechanic, its own module behind the SimContext seam, never a method cluster on sim.ts
  • New effect kinds, only where an existing AbilityEffect does not already cover it
Presentation and hosts
  • Class color, one entry wherever class colors are read (party frames, player card, minimap, tooltips)
  • Character creation, the tenth option and its model
  • i18n, English keys only, in the matching src/ui/i18n.catalog module
  • Wiki, regenerated guide content plus the new prose keys
  • Tests, sim coverage for the Citation ladder, plus the class and talent content pins

The one rule this class must not break

The Game Master resembles the staff toolbox. It must never be the staff toolbox. Every ability resolves server-side under the same authority as any other class: no dev command path, no admin permission check, no client-decided outcome, and nothing that behaves differently when ALLOW_DEV_COMMANDS is set. Under Review is deliberately not called Spectate for exactly this reason: it is a combat vision effect on a hostile target, and it must never be confused in a code search with the moderation spectate view it was named after.

Three calls that are yours

Whether Authority is worth a display rename over plain mana, given every resource label and bar color it touches. Whether Conjured Adventurer is acceptable at all, since a summoned stand-in interacts with group content rules and the dungeon finder. And whether the class ships at three specs or opens at two, with Oversight held back until the Citation ladder has been measured in a real raid.
